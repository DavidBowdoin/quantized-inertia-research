# Casimir effect and the uncertainty principle

**Citation:** Giné, J. (2018). *Casimir effect and the uncertainty principle*. Modern Physics Letters A, 33(24), 1850140. https://doi.org/10.1142/S0217732318501407 (published online 3 Aug 2018).

**TL;DR:** A heuristic attempt to "deduce the Casimir effect directly from the uncertainty principle". It uses the same style of reasoning (vacuum fluctuations plus Heisenberg Δx–Δp with geometric choices for Δx) as Giné's companion EPL paper on the Hawking and Unruh temperatures and as McCulloch's uncertainty-principle derivations of QI. The paper does not test QI itself. It is part of the method base that QI papers draw on.

> Paywalled. No PDF is stored. This summary is based on the abstract (Crossref / OpenAlex) and the reference list in Crossref.

## Key claims
- From the abstract: "The Casimir effect is one of the observable consequences of the vacuum fluctuations. The Casimir effect manifests itself as a force between two uncharged conductive plates in a vacuum placed a few nanometers apart. In this work, we try to deduce the Casimir effect directly from the uncertainty principle."
- The Crossref reference list (16 entries) includes McCulloch 2013 (EPL 101, 59001, "Inertia from an asymmetric Casimir effect"), Giné 2012 (MPLA 27, holographic modified inertia), Giné 2017 (IJMPA 32, inertial mass from the holographic scenario), Giné 2018 (EPL 121, 10001), and two Hajdukovic papers on the gravitational properties of the quantum vacuum. This places it in the QI / modified-inertia context.

## Key equations
> [!UNVERIFIED] The full text was not available, so the paper's equations are not reproduced. For reference, the standard result it aims to recover is the Casimir pressure between ideal parallel plates, $P = -\pi^2\hbar c/(240\,d^4)$. Whether the paper recovers this exact coefficient was not checked.
