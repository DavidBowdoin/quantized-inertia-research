# Physics from the Edge: A New Cosmological Model for Inertia

**Citation:** McCulloch, M. E. (2014). *Physics from the Edge: A New Cosmological Model for Inertia*. Singapore: World Scientific. ISBN 978-981-4596-25-1 (print), 978-981-4596-26-8 (ebook). https://doi.org/10.1142/9122 (published online 21 Feb 2014, per Crossref).

**TL;DR:** McCulloch's first book. It presents MiHsC (Modified inertia due to a Hubble-scale Casimir effect, later called quantised inertia) for a general/semi-technical reader: the history of ideas about inertia, the low-acceleration problems MiHsC addresses, the claimed evidence, and proposed experimental tests. The description says it uses simple maths and many cartoons by the author.

## Key claims
- From the publisher-style description (as relayed by retailer/catalogue listings): MiHsC "explains inertia for the first time" and also predicts galaxy rotation without dark matter, cosmic acceleration and some other anomalies; the book covers evidence for, and tests of, the theory. These are the author's claims.
- Inertia arises from Unruh radiation seen by accelerating objects, with wavelengths limited by the Hubble-scale horizon (a "Hubble-scale Casimir effect"); see the papers in `01-papers/` for the technical versions.
